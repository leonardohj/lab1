REST API e Java — Explicado de Forma Simples

Esta página explica REST APIs e como usá-las com Java, de forma clara e direta, como se estivéssemos só a conversar.

1. O que é uma REST API?

REST (Representational State Transfer) é uma forma de organizar como programas diferentes comunicam entre si. É muito usado para criar APIs, que são maneiras de um programa pedir informações a outro.

1.1 Princípios do REST

  • Cliente e Servidor separados — cada macaco no seu galho
  • Não guardam a informação entre pedidos
  • Usa cache

1.2 Métodos HTTP mais usados

  • GET – buscar
  • POST – mandar/criar
  • PUT – atualizar
  • DELETE - apagar

2. Como funciona a comunicação REST?

Um cliente (utilizador, o browser, uma app, etc.) envia um pedido para o servidor, e o servidor responde normalmente em JSON.

Utilizador → API → JSON

Exemplo de uma resposta JSON:

{
  "id": 1,
  "title": "Aprender REST",
  "completed": false
}

3. REST API no Frontend (JavaScript)

No frontend, usamos fetch(), que é super simples para ir buscar dados a APIs. É tipo mandar mensagem e receber resposta.

3.1 Exemplo: Obter utilizadores de uma API pública

        <button id="load">Carregar Utilizadores</button>
        <pre id="content"></pre>
        
        <script>
        document.getElementById("load").addEventListener("click", () => {
            fetch("https://jsonplaceholder.typicode.com/users")
                .then(res => res.json())
                .then(data => {
                    document.getElementById("content").innerText =
                    JSON.stringify(data, null, 2);
                })
                .catch(() => {
                    document.getElementById("content").innerText =
                    "Ups... deu erro ao carregar os utilizadores.";
                });
        });
        </script>

4. REST API no Backend com Java

No Java, também podemos consumir APIs, com o uso de ferramentas que já vêm incluídos ou com frameworks como o Spring.

4.1 Consumir uma API com Java 11+ (HttpClient)

import java.net.http.*;
import java.net.URI;

public class ApiExample {
    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();

        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create("https://api.com/api/"))
                .build();

        HttpResponse<String> response =
                client.send(request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
}

4.2 Consumir API usando Spring Boot (RestTemplate)

@RestController
public class ApiController {

    @GetMapping("/todo")
    public String getTodo() {
        RestTemplate rt = new RestTemplate();
        String url = "hhttps://api.com/api/";
        return rt.getForObject(url, String.class);
    }
}

4.3 Criar a tua própria REST API com Java (exemplo com: Spring Boot)

@RestController
@RequestMapping("/api")
public class UserController {

    @GetMapping("/user")
    public Map<String, String> getUser() {
        return Map.of(
            "id", "1",
            "nome", "João Costa PRO"
        );
    }
}
